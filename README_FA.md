# KORG-Shahzade — نسخه اولیه رابط کاربری

این فایل ZIP شامل **پروژه منبع اندروید** برای نسخه نمایشی اولیه است؛ APK آماده نیست.

## امکاناتی که در این نمونه کار می‌کنند
- اجرای افقی و پنل اولیه الهام‌گرفته از چیدمان Pa700
- نمایشگر وضعیت، انتخاب نمایشی دو صدای نمونه
- افزایش/کاهش Tempo از 30 تا 300
- Transpose نیم‌پرده‌ای از 12- تا 12+ و Reset
- دکمه Start/Stop نمایشی برای وضعیت Style
- انتخاب تعداد کلاویه و نت شروع در Settings
- جابه‌جایی بین یک ردیف و دو ردیف کلاویه
- صفحه تنظیمات جداگانه

## محدودیت مهم
این نسخه **نمونه رابط کاربری** است، نه ارنجر کامل و نه شبیه‌ساز واقعی KORG Pa700.
هنوز موتور صوتی، نمونه‌صداهای سازها، ریتم‌های واقعی، تشخیص آکورد، فایل‌های SET اختصاصی، ضبط WAV، واردکردن فایل‌ها و اتصال MIDI پیاده‌سازی نشده‌اند. بعضی دکمه‌های پنل فعلاً فقط ظاهر اولیه دارند و عملکرد موسیقایی ندارند. پشتیبانی از فایل‌های اختصاصی Pa700 باید جداگانه و با فایل‌های مجاز و آزمون فنی توسعه داده شود.

## باز کردن پروژه
1. ZIP را استخراج کن.
2. پوشه `KORG-Shahzade` را در Android Studio باز کن.
3. اجازه بده Gradle همگام‌سازی شود.
4. برنامه را روی گوشی اجرا کن.

پروژه با Android Gradle Plugin 8.7.3، Kotlin 2.0.21 و SDK 35 تنظیم شده است.
برای ساخت APK به محیطی نیاز است که Android SDK و Gradle را اجرا کند.
